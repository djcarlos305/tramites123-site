Situación real

¿Cuándo usar esta herramienta?

Una receta, una caja, una habitación o un formulario usa una medida distinta a la que tienes. Este convertidor evita hacer cuentas rápidas y equivocarte entre pulgadas, centímetros, libras, kilos y más.

Bueno saberlo

El resultado es matemático. Si un formulario exige una medida oficial, usa la fuente o instrumento que indique la institución.

Cómo usarla

  1. Elige la categoría de medida.
  2. Escribe la cantidad y selecciona las dos unidades.
  3. Copia o anota el resultado con la precisión que necesitas.

Preguntas frecuentes

¿Qué unidades puedo convertir?

La herramienta incluye categorías comunes como longitud, peso, temperatura y volumen.

¿Debo redondear el resultado?

Depende del uso. Para una receta puede bastar una cifra simple; para un requisito oficial, sigue sus instrucciones de redondeo.
