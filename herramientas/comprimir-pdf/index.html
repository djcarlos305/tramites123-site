Comprimir PDF

Reduce el tamaño de un PDF para enviarlo por correo o subirlo a un portal.

Más baja produce un archivo menor. El texto se convierte en imagen.

🔒 El PDF se procesa en tu dispositivo.

Cómo comprimir un PDF

Selecciona el archivo, elige el nivel de calidad y descarga la copia comprimida. Revisa el resultado antes de borrar el documento original.

Ejemplo práctico

Un PDF escaneado de 12 MB puede reducirse lo suficiente para enviarlo por correo, aunque el resultado depende del número de páginas y de la resolución de las imágenes.

Limitaciones importantes

La herramienta vuelve a crear las páginas como imágenes. El texto seleccionable, enlaces y formularios interactivos pueden perderse. Los PDF protegidos pueden no abrirse.

Preguntas frecuentes

¿Mi PDF se carga al servidor?

No. El procesamiento ocurre localmente en tu navegador.

¿Por qué algunos archivos casi no reducen su tamaño?

Los PDF ya optimizados o formados principalmente por texto pueden tener poco margen de compresión.

¿Se conserva la misma calidad?

La compresión reduce calidad visual para ahorrar espacio. Elige un nivel más alto cuando el texto sea pequeño.
