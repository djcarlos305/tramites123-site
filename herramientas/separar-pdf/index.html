Documentos y PDF

Separar PDF y extraer páginas

Elige páginas específicas y crea un PDF nuevo directamente en tu navegador.

Separa rangos con guiones y páginas individuales con comas.

🔒 El archivo se procesa en tu dispositivo y no se carga a nuestro servidor.

Cómo separar un PDF

Selecciona el archivo, escribe las páginas que necesitas y descarga el documento nuevo. Puedes combinar rangos y páginas individuales, como 1-4, 7, 10.

Cuándo resulta útil

Extrae recibos, contratos, formularios o páginas importantes sin compartir el documento completo.

No funciona con archivos protegidos por contraseña. Verifica el resultado antes de enviarlo.

Situación real

¿Cuándo usar esta herramienta?

Tienes un PDF largo y solo necesitas enviar una página, separar anexos o guardar partes por separado. Esta herramienta crea una copia nueva con las páginas que selecciones.

Bueno saberlo

Separar un PDF no cambia el archivo original. Conserva una copia y revisa si el destinatario necesita el documento completo.

Cómo usarla

  1. Selecciona el PDF y revisa los números de página.
  2. Indica qué páginas quieres extraer.
  3. Descarga la copia y verifica que incluya todo lo necesario.
