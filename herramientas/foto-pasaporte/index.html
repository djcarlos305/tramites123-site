Preparar foto 2×2

Recorta una fotografía cuadrada de 600×600 píxeles para imprimir o revisar antes de una solicitud.

Esta herramienta solo prepara el tamaño. Revisa los requisitos oficiales de fondo, iluminación, expresión y fecha antes de presentar la foto.

Situación real

¿Cuándo usar esta herramienta?

Necesitas una foto cuadrada 2×2 para imprimir o revisar antes de una solicitud, pero solo tienes una foto en el teléfono. Esta herramienta prepara una copia con ese formato básico.

Bueno saberlo

La herramienta no garantiza que una agencia, consulado, empleador o portal acepte la foto. Cada requisito puede cambiar.

Cómo usarla

  1. Elige una foto clara con el rostro visible.
  2. Ajusta el encuadre y revisa la vista previa.
  3. Descarga la copia y revisa las reglas del destinatario antes de imprimir o enviar.
