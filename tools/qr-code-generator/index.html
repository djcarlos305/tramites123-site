Create a free QR code for a link, WhatsApp, email, phone number or text.

Real-life use

When would I use this tool?

You want someone to open a link, WhatsApp chat, menu, payment page or form from a phone without typing a long address. A QR code turns that information into something scannable.

Good to know

A QR code contains exactly the text or link you add. Check for mistakes before distributing it.

How to use it

  1. Paste a link or type the text you want to share.
  2. Generate the code and download it as an image.
  3. Scan it with your phone before printing or sharing it.

Frequently asked questions

Do QR codes expire?

The code itself does not expire, but it stops working if its destination link stops working.

Can I use one for WhatsApp or email?

Yes, when you use the correct link or format. Test it with a phone before sharing it.
