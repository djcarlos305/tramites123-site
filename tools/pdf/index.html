Practical guide

Choose the right PDF tool for the job

This collection helps you prepare documents for sending, storing or sharing without installing software. Pick a task, process the file on your device and download a new copy.

Privacy first

The tools in this collection process files in your browser and do not require an account.

Three simple steps

  1. Choose the task: merge, compress, split, organize, convert or watermark.
  2. Make a copy before changing an important document.
  3. Review the downloaded file before sending it to a portal or by email.

Common situations

Merge documents for one submission packet. Use the compressor when a portal has a file-size limit. Split or convert a PDF when you only need one page.

Frequently asked questions

Are my PDF files uploaded to a server?

No. These tools process the file locally in your browser; the file is not stored by this website.

Which tool should I use to reduce a file size?

Use Compress PDF. Review the downloaded copy because stronger compression can reduce visual quality.
