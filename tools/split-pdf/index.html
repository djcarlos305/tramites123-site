How to split a PDF

Select the file, enter the pages you need and download the new document. Combine ranges and individual pages, such as 1-4, 7, 10.

When it is useful

Extract receipts, contracts, forms or important pages without sharing the complete document.

Password-protected files are not supported. Review the result before sending it.

Real-life use

When would I use this tool?

You have a long PDF and only need to send one page, separate attachments or store parts individually. This tool creates a new copy with the pages you select.

Good to know

Splitting a PDF does not change the original file. Keep a copy and check whether the recipient needs the full document.

How to use it

  1. Choose the PDF and review page numbers.
  2. Select the pages you want to extract.
  3. Download the copy and verify it includes everything needed.
