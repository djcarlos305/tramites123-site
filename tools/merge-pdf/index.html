Merge PDF Files

Combine multiple PDF documents into one file in the order you select.

🔒 Your files are processed on this device and are not stored by our website.

How to merge PDF files

Select two or more documents in the desired order and create one copy. Arrange the files first because that becomes the final order.

Practical example

Combine a cover page, application and supporting documents into one file for storage or submission.

Important limitations

Password-protected or restricted documents may fail. This tool does not correct rotated pages or automatically reduce the final file size.

Frequently asked questions

How many PDFs can I merge?

The practical limit depends on your device memory and the size of the files.

Do the documents leave my device?

No. Merging happens locally in the browser.

Can I change the order afterward?

Use our Organize PDF tool after creating the combined file.
